# EcommerceAppFullStack

A full-stack e-commerce application with modern features and responsive design.

## Overview

This project is a complete e-commerce solution featuring a responsive frontend, robust backend and order management.

## Features

- Product catalog with search and filtering
- Shopping cart functionality
- Order history and tracking
- Admin dashboard for product and order management
- Responsive design for mobile and desktop

## Technologies Used

### Frontend
- HTML, CSS
- Angular

### Backend
- .NET microservices 
- RESTful API architecture
- MSQL database

## Installation

```bash
# Clone the repository
git clone https://github.com/Raghad-Alahmadi/EcommerceAppFullStack.git

# Navigate to the project directory
cd EcommerceAppFullStack

# Install dependencies
npm install
ng serve


## Usage

1. Browse products by category
2. Add items to your shopping cart
3. Proceed to checkout
4. Complete payment and track your order

## API Documentation

API endpoints are available at `/api/v1/` with the following resources:

- `/api/v1/products` - Product management
- `/api/v1/users` - User management
- `/api/v1/orders` - Order processing
